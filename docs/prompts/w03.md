# w03 : programme officiel (GitHub Universe), Sessionize, Sched

Dossier : backend/app/providers/events/official. Bloc : 05-events.md, 03-demo-scenario.md.

Subagents : A Universe, B Sessionize + Sched, C tests et fixture.

A. Universe (`official/github_universe.py`)
- Cible : catalogue des sessions et page speakers de GitHub Universe 2026 (githubuniverse.com, reg.githubuniverse.com). Les pages sont dynamiques. Ordre d'attaque : 1) httpx GET et chercher un JSON embarqué (`__NEXT_DATA__`, `window.__INITIAL_STATE__`, script type application/json) ou un endpoint XHR visible dans le HTML (fetch vers /api/, .json, GraphQL) ; 2) si rien, Browser API Bright Data (Playwright connect_over_cdp sur BRIGHTDATA_BROWSER_WSS) avec interception des réponses réseau JSON ; 3) si pas de clé, Playwright local headless (installer chromium) ; 4) sinon fixture. Documenter dans probes/ l'endpoint trouvé.
- Extraire Session (titre, abstract, start/end local Pacific + UTC, salle, track, speakers avec nom, titre, entreprise, photo, liens) et Person pour chaque speaker (présence confirmed sur sa session), Company pour chaque entreprise, sponsors et exposants (Company avec SPONSORS). Page "evening events" ou "Speaker After Parties" si trouvable → SideEvent.
- Normalize vers Session / Person / Company des schémas core.

B. Sessionize (`official/sessionize.py`) : détecter l'endpointId dans le HTML d'un site de conf (regex `sessionize.com/api/v2/([a-z0-9]+)`), GET /view/All, parser sessions, speakers (bio, liens sociaux), rooms. Sched (`official/sched.py`) : pages publiques `<event>.sched.com/list/descriptions` et `/directory/speakers`, parser best effort. Les deux génériques, testés sur une conf publique qui les utilise (trouve-en une via recherche web, par ex. une conf 2026 sur Sessionize).

C. `run(conference)` avec conference {id, name, url, lat, lng, dates} ; Makefile `probe-events-official` ; fixture `fixtures/events-official.json` (40 sessions Universe crédibles sur 2 jours, 60 speakers, 25 entreprises dont AMD, Figma, NVIDIA, Coinbase, Anthropic, OpenAI, 8 investisseurs seed) ; tests parseurs sur HTML et JSON figés.
