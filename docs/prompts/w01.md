# w01 : events Luma + Partiful

Dossiers : backend/app/providers/events/luma, backend/app/providers/events/partiful. Bloc : docs/knowledge/05-events.md.

Subagents en parallèle : A Luma, B Partiful, C tests et fixture.

A. Luma (`luma/source.py`, classe LumaSource implementing Source)
- `discover(query)` : GET https://api2.luma.com/discover/get-paginated-events avec latitude, longitude, pagination_limit=50, pagination_cursor (jamais `cursor`, jamais `slug`), headers Accept json et Referer https://luma.com/. Drainer jusqu'à has_more false ; curseur répété = termination cursor_stuck ; max 60 pages = page_cap ; 300 ms entre pages. Map par api_id. RunReport complet. Filtrer ensuite sur query.date_from/date_to et rayon (haversine).
- Transport : httpx direct ; si 403 ou 429 persistant, retenter via core.brightdata.unlock (si clé) sinon termination blocked.
- `fetch_details(ref)` : page https://luma.com/<slug> via unlock si clé sinon httpx, parser `__NEXT_DATA__` : description, hôtes (nom, url), lieu exact ou null, nombre d'inscrits, invités visibles (nom, photo, entreprise si présente) dans `payload.guests_visible`. Lieu caché = null.
- `normalize(record) -> Event` : dates local + IANA + UTC, venue avec geo_precision, organizers, pricing, capacity, status, sources[] avec raw et content_hash. Copier et adapter `backend/scrapers/luma.py` et `timezone.py` d'ai-eventscraper si utile (en-tête de provenance), sans le Kuala Lumpur codé en dur ni date du jour.

B. Partiful (`partiful/source.py`)
- GET https://partiful.com/explore/sf → buildId dans `__NEXT_DATA__` ; GET https://partiful.com/_next/data/{buildId}/explore/sf.json ; 404 = re-scraper le buildId une fois, driftSignals.buildIdRotated ; unir trendingSection.items, sections[].items, feedItems, dédup par event.id ; expected_count = pageProps.regionEventCounts.SF. Normalize vers Event. Invités : non (Browser API connecté = phase 2, laisser un TODO et une interface `fetch_guests` qui lève NotImplemented).

C. `run(query)` dans `events/luma/__init__.py` et `partiful/__init__.py`, Makefile `probe-events-luma` et `probe-events-partiful`, fixtures `fixtures/events-luma.json` (12 side events réalistes autour de Fort Mason 27 au 30 octobre, dont Syntax Meetup le 27 et deux events simultanés le 28 soir) et `fixtures/events-partiful.json` (6). Tests : pagination mock (3 pages puis has_more false), curseur bloqué, 404 buildId, normalisation fuseaux.

Sans clé ce soir : les endpoints sont publics, tente le live réellement et écris les vraies réponses tronquées dans probes/.
