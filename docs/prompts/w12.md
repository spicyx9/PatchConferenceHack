# w12 : API et page de démo

Dossiers : backend/app/api, frontend. Bloc : 03-demo-scenario.md, 01-vision.md, 14-market-landscape.md (pitch).

Tout fonctionne sur fixtures dès ce soir, avec badge `data_source` visible partout ; chaque route appelle le module réel s'il est importé (import dynamique) sinon la fixture.

Subagents : A routes, B page, C graphe et carte, D tests.

A. Routes FastAPI (`api/routes/*.py`) : GET /health (SHA git, versions, graphe up) ; POST /goal {text, conference_id, user_id} → goals + plan + people (appelle agents.planner.run) ; GET /plan ; GET /people ; GET /events (filtres jour, type, score) ; GET /sessions ; GET /stays ; GET /flights ; GET /travel (itinerary, proposals, budget) ; GET /travel/map ; GET /graph (graph_for_ui, filtre par type, limite 400) ; GET /graph/path?user&person ; POST /met {person_id, note} ; POST /attended, /skipped ; POST /simulate-change {scenario_id} ; GET /scenarios ; POST /proposal/accept ; GET /roi. CORS ouvert. Réponses avec data_source et collected_at.

B. `frontend/index.html` (une page, vanilla JS, CSS propre, sans framework) : onglets Dashboard (objectif saisi, 4 chiffres ROI, prochaines actions), Travel (vol choisi, hôtel choisi avec price_status et lien, legs du trajet, propositions avec boutons accepter), Events (programme jour par jour, conflits avec verdict Anti-FOMO et "ce que tu rates"), Graph (cytoscape.js via CDN, nœuds colorés par type, clic sur une personne → chemin surligné depuis User), People (top 10 cartes : qui, pourquoi, où, comment, présence, bouton Rencontré avec note). Barre du haut : champ objectif + bouton Lancer, badge global live/fixture, bouton "Simuler un changement" (liste des scénarios) qui affiche le diff. Lisible en démo sur un projecteur : grandes polices, contraste.

C. Graphe : cytoscape layout cose, 400 nœuds max, légende ; carte : Leaflet + OSM, marqueurs et polylignes depuis /travel/map ; les deux rafraîchis après /goal, /met, /simulate-change.

D. Tests API (TestClient) sur fixtures pour chaque route ; test que /goal avec le texte de démo renvoie ≥ 5 personnes et un plan sur 2 jours. Makefile `demo` (up, seed, uvicorn, ouvre le navigateur). Capture d'écran de chaque onglet dans demo/screens/ via Playwright.
