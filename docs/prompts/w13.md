# w13 : fixtures cohérentes, scénarios, script de démo, run de secours

Dossiers : fixtures, scripts/gen_fixtures.py, demo. Bloc : 03-demo-scenario.md, 02-hackathon.md.

Subagents : A générateur, B scénarios, C démo.

A. `scripts/gen_fixtures.py` : déterministe (seed 42), produit toutes les fixtures d'un coup, cohérentes entre elles (les ids se répondent) : events-official.json (40 sessions Universe 28 et 29 octobre, salles Fort Mason, 60 speakers, 25 entreprises dont AMD, Figma, NVIDIA, Coinbase, Anthropic, OpenAI, GitHub, 8 investisseurs seed), events-luma.json (12 side events 27 au 30 octobre, hosts = entreprises ou speakers, 2 events simultanés le 28 soir à 1,5 km l'un de l'autre, Syntax Meetup le 27), events-partiful.json (6), events-eventbrite.json (8), events-aggregators.json (vraies données publiques conferenceparties reinvent2026, 20 events, pour montrer la généricité), events-discovery.json (10), people.json (120 : chaque speaker, chaque host, 15 fondateurs agents IA, 5 PM Copilot, 8 investisseurs, topics et rôles, presences confirmed ou probable, 30 % sans linkedin_url), companies.json (25), stays.json (15 avec price_status variés, distances), flights.json (6, montants en chaînes), travel.json, plan-demo.json, emails/ (6 .eml). Tous avec `source: fixture`, `fetched_at` fixe. Validés contre core.schemas (le script échoue si un objet est invalide).

B. `fixtures/scenarios.json` : 3 scénarios simulate-change (sold_out sur un des deux events simultanés du 28, new_event avec 2 personnes cibles le 29 soir, time_change d'un talk créant un conflit) avec l'état attendu après replan.

C. `demo/SCRIPT.md` : script 3 minutes chronométré (03-demo-scenario.md), qui parle, qui clique, quel onglet à quelle seconde, les 3 phrases qui nomment les critères FalkorDB et Bright Data ; `demo/CHECKLIST.md` : avant de monter sur scène (docker up, seed, clés, navigateur en plein écran, vidéo de secours prête, Qodo PR ouverte dans un onglet) ; `demo/record.sh` : enregistre un run complet (Playwright + ffmpeg si dispo, sinon captures) dans demo/backup/ ; `demo/PITCH.md` : 6 phrases de positionnement depuis 14-market-landscape.md. Makefile `fixtures` et `record`.
