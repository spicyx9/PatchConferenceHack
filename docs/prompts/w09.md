# w09 : agents Reverse Planning + Smart Networking

Dossiers : backend/app/agents/planner, backend/app/agents/networking. Bloc : 10-agents-planning.md, 08-people.md, 09-graph.md.

Démarre sur fixtures et sur le graphe seedé (make seed) ; si w08 n'est pas mergé, utilise une implémentation locale minimale des requêtes sur fixtures derrière la même interface et marque TODO.

Subagents : A goal parser + scoring, B planner, C networking, D tests et fixture.

A. `planner/goals.py` : parse_goals(text) → list[Goal] via OpenAI structured output (topics, target_roles, count, weight somme 1), garde-fou (vide ou incohérent → objectifs par défaut), écriture HAS_GOAL, TARGETS, TARGETS_ROLE via graph.ingest_goals. `planner/scoring.py` : U(o) avec les composantes et poids de 10-agents-planning.md, fonction pure sur un objet Candidate {kind, id, goal_paths[], target_people_confirmed, target_people_probable, topic_similarity, company_novelty, duration_min, travel_min, cost, uncertainty} ; renvoie score + breakdown + explanation text.

B. `planner/plan.py` : candidats (events_for_goal + sessions + side events AROUND ≥ 0.5), scoring, puis optimiseur glouton par jour avec contraintes (pas de chevauchement en comptant le trajet, max 6 items par jour, créneaux bloqués vol et check-in, items fixés), un subagent par jour en parallèle ; w10 remplacera par l'optimiseur Pathfinder derrière la même interface `optimize(candidates, constraints, original=None)`. Sortie Plan {days[] {items[] {kind, id, start, end, venue, score, reason, path, travel_from_previous}}, rejected[] {id, reason}}. `run(user_id, goal_text, conference_id)`.

C. `networking/recommend.py` : appelle providers.people.match (ou fixtures), applique les ajustements graphe (MET et CONTACTED exclus, company_coverage malus, présence confirmed bonus, chemin court bonus), top 10 avec qui, pourquoi (chemin texte via graph.explain), où (session ou side event, heure, lieu), comment (opener), présence, confiance. `networking/memory.py` : met(user_id, person_id, note) → record_memory puis re-rank immédiat (preuve de mémoire pour la démo).

D. Tests : parse_goals sur le texte de démo donne 3 objectifs avec poids 0.45 0.35 0.20 (tolérance), scoring monotone, plan sans chevauchement, MET sort du top. Fixture `fixtures/plan-demo.json` (plan attendu pour le scénario, utilisé par w12 en secours). Makefile `probe-agents-planner`.
