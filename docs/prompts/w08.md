# w08 : Opportunity Graph (FalkorDB)

Dossier : backend/app/graph. Bloc : 09-graph.md, 05-events.md (rattachement).

Subagents : A schéma et ingestion, B requêtes nommées, C GraphRAG textes, D tests et vue UI.

A. `graph/schema.py` : labels, arêtes et props de 09-graph.md, index sur id de chaque label, index fulltext sur Topic.name, Person.name, Session.title. `graph/ingest.py` : `ingest_events(list[Event])`, `ingest_sessions`, `ingest_people`, `ingest_companies`, `ingest_lodging`, `ingest_flights`, `ingest_goals(user_id, goals)` ; tout via core.store MERGE idempotent ; arêtes AROUND avec score et signals depuis conference_link ; ATTENDING status depuis presences ; props source, confidence, observed_at sur chaque arête. `graph/seed.py` : charge toutes les fixtures/*.json et remplit le graphe (make seed).

B. `graph/queries.py` : people_for_goal, events_for_goal, conflicts, path_user_to_person, company_coverage, people_met_before, replan_after_change, graph_for_ui, plus `record_memory(user_id, kind MET|ATTENDED|SKIPPED|CONTACTED, target_id, note)`. Chaque fonction renvoie {rows, paths} où paths = liste de {nodes[], edges[]} sérialisables (pour cytoscape et pour l'explication texte). Cypher dans des chaînes nommées, paramétrées, jamais de f-string avec des valeurs.

C. `graph/textgraph.py` : FalkorDB GraphRAG-SDK avec GraphSchema restreint (Person, Company, Topic, Session, SideEvent ; ABOUT, WORKS_AT, INTERESTED_IN) pour extraire Topic et ABOUT depuis bios, abstracts, descriptions ; écrit via core.store ; index vectoriel sur Topic.name et Session.abstract (embeddings OpenAI) et `similar_topics(text, k)`.

D. Tests sur FalkorDB docker (skip si absent) : seed puis chaque requête renvoie des chemins pour le scénario de démo (Goal "fondateurs agents IA" → au moins 5 personnes avec chemin de longueur 2 à 4). `graph/explain.py` : `path_to_text(path)` qui produit la phrase du type "Marie X donne le talk ... et sa boîte organise ... le soir même à 12 min". Makefile `probe-graph` (seed + 3 requêtes + capture du nombre de nœuds). Installer FalkorDB/skills dans .claude/skills si absent.

Le browser FalkorDB sur localhost:3000 doit montrer le graphe après make seed : vérifie-le.
