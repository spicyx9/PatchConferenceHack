# w05 : logements (Booking, Google Hotels, Airbnb)

Dossier : backend/app/providers/stays. Bloc : 06-lodging.md, 13-brightdata.md.

Ordre imposé : d'abord les sondes, puis les adaptateurs à partir des vraies réponses. Sans clé : structure, pyairbnb, fixture, tests mock ; les adaptateurs Bright Data sont écrits sur les champs documentés et marqués à confirmer.

Subagents : A sondes + Booking, B Google Hotels, C Airbnb, D normalisation, vérification, dédup, distances, fixture, tests.

A. `stays/probe.py` : avec clé, un appel réel par dataset (gd_m4bf7a917zfezv9d5 Booking search ; gd_mdy9ld3p1e0oqlj9g4 fiche avec sb_price_type=total sur une URL renvoyée ; gd_mg3gjfmg12tc2n5d4d Google Hotels ; gd_ld7ll037kqy322v05 Airbnb) pour San Francisco, 27 au 30 octobre 2026, adults 1, USD, limit_per_input 5 ; sauvegarder les réponses brutes dans probes/raw/ et un résumé des champs (noms, types, exemples) dans probes/stays.md. Si un dataset id est refusé, appeler l'API de catalogue (GET https://api.brightdata.com/datasets/list ou docs.brightdata.com/scrapers/<id>.json) et noter l'id correct dans DECISIONS.md.
- `stays/booking.py` : BookingProvider.search(query) via core.brightdata.scrape_sync (discover_by input_filters si c'est le mode du dataset) puis `verify(candidates)` sur le top 15 via le dataset fiche. Normalize vers Lodging avec price_status.

B. `stays/google_hotels.py` : GoogleHotelsProvider via gd_mg3gjfmg12tc2n5d4d (search_term "hotels near Fort Mason Center San Francisco", check_in_date, check_out_date, guest_number 1, country us, currency USD). Garder booking_options (vendeur, prix, url) ; lat/long ; pivot de dédup. Fallback SerpApi google_hotels si SERPAPI_KEY.

C. `stays/airbnb.py` : AirbnbProvider avec deux implémentations derrière la même interface : PyAirbnb (pip pyairbnb, search_all sur bounding box 3 km autour de 37.8060,-122.4320 avec check_in, check_out, currency USD, puis get_price sur top 10, get_calendar si doute) et BrightDataAirbnb (gd_ld7ll037kqy322v05). Bascule sur erreur de schéma, blocage, timeout, champs prix absents ; pas sur zéro résultat. geo_precision approximate.

D. `stays/normalize.py` (price_status, total du séjour, nightly_avg calculé, frais null si inconnus, includes_all_fees, market_context), `stays/dedupe.py` (75 m + nom normalisé), `stays/distance.py` (haversine + minutes marche vers Fort Mason et vers une liste de lieux passée en paramètre), `stays/service.py` (asyncio.gather des trois, cache 30 min clé (provider, id, dates, adults, currency)), `run(query)` avec query {lat, lng, radius_km, check_in, check_out, adults, currency, venues[]}. Makefile `probe-stays`. Fixture `fixtures/stays.json` (15 logements : 8 hôtels Booking, 4 Google Hotels avec booking_options, 3 Airbnb, price_status variés, distances réalistes). Tests : normalisation, price_status, dédup, bascule Airbnb.

Rappel absolu : un lien n'est réservable qu'en verified_bookable ; frais inconnu = null.
