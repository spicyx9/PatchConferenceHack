# Scénario de démo (figé)

## Conférence

GitHub Universe 2026, 28 et 29 octobre, Fort Mason Center, San Francisco (lat 37.8060, lng -122.4320). Programme et speakers publiés (AMD, Figma, NVIDIA, Coinbase, Anthropic, OpenAI). Mardi 27 : programmation sur invitation. Speaker After Parties officielles dans GitHub Central. Hôtels autour de Fort Mason : médiane 270 $/nuit la semaine de la conf (Navan, 2025), les hôtels à distance de marche saturent.

Side events : essentiellement sur Luma (ex. San Francisco Syntax Meetup, 520 inscrits, la veille), sur les sites des exposants (ex. happy hour NeuBird + FluidCloud), sur Partiful. La page conferenceparties.com/github26 existe mais est vide : ne pas compter dessus pour Universe.

URL réelles pour tester (pages dynamiques, Browser API ou JSON derrière la page) : catalogue de sessions et page speakers sur githubuniverse.com et reg.githubuniverse.com ; side events Luma "Ship & Sip (Sentry x LaunchDarkly)" et "Agents After Dark (Founders Bay)".

## Utilisateur de démo

New York → San Francisco, départ 27 octobre, retour 30 octobre, 1 adulte, économie, budget total 2 500 $.

Objectif saisi en langage naturel : "Fondateur d'un outil dev IA, je vais à GitHub Universe pour rencontrer des investisseurs seed, des fondateurs d'agents IA et des PM Copilot."

Objectifs pondérés attendus après extraction : investisseurs seed (0.45), fondateurs agents IA (0.35), PM Copilot (0.20). Sujets : AI agents, developer tools, Copilot, MCP.

Aéroports : JFK, LGA, EWR → SFO, OAK, SJC.

## Script 3 minutes

0:00 Problème : 2 jours de conf, 60 side events, 3 000 personnes, on rentre avec 4 cartes de visite. Conferge part de l'objectif, pas de l'agenda.
0:20 Saisie de l'objectif. Le graphe se remplit en direct (badge source : Bright Data live).
0:50 Top 10 personnes : pour chacune, pourquoi (chemin dans le graphe affiché dans le browser FalkorDB), où (talk, salle, heure ou side event), comment l'aborder (phrase d'accroche).
1:30 Programme Reverse Planning jour par jour. Anti-FOMO : deux events simultanés le 28 soir, verdict expliqué, et ce qu'on rate.
2:00 Voyage : vol choisi avec proposition proactive ("arriver le 27 pour le Syntax Meetup"), hôtel à 12 min de Fort Mason, prix total avec statut verified_bookable, lien direct, carte.
2:30 Live Replanning : bouton "simuler un changement" (un event devient complet), le programme se recalcule, diff affiché. Bouton "rencontré" sur une personne : le classement change, mémoire persistée.
2:50 Ce qui est réutilisable : le graphe reste pour la prochaine conf.
